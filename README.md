# Live My Training Clone

Static frontend boilerplate based on the supplied eLearning template and the public Live My Training site structure.

## Pages
- index.html
- about.html
- courses.html
- course.html
- projects.html
- project.html
- experts.html
- blog.html
- blog-post.html
- contact.html
- account.html
- checkout.html
- 404.html

## Backend placeholders
Payment, cart/order APIs, login/registration, protected video playback, downloadable content, certificates and form submission are deliberately UI-only. Search for `data-placeholder` and the form handlers in the HTML/JS to connect real services.

## Run
Open `index.html` directly or serve the folder with a static server.
